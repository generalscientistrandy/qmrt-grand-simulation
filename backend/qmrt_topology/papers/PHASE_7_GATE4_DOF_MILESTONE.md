## Analysis

### 1. Organization is Hybrid

No single DoF has overwhelming explanatory power:
- All individual correlations |r| < 0.3
- Top 3 DoFs closely spaced (0.33–0.42)
- Control is distributed across multiple degrees of freedom

### 2. DoF Roles Clarified

| DoF | Role in Organization |
|-----|---------------------|
| **Position (radial_dist)** | Weak but broad influence across all organizational features |
| **Coupling (κ-landscape)** | Moderate influence, especially on hub formation |
| **Resonance (channel state)** | Moderate influence, especially on node degree |
| **Topology (winding)** | Gatekeeper variable—enables defects but doesn't predict connectivity |
| **Memory (remnant)** | Historical enabler—enables regeneration but doesn't shape current structure |

### 3. Key Distinctions

**Topology as Gatekeeper**
- Topology determines *existence* of defects
- Topology matters for population maintenance and regeneration
- But topology does NOT directly predict degree, clustering, or hub status
- It is a **gatekeeper variable**, not an organizational predictor

**Memory as Historical Enabler**
- Remnant fields matter for *where* defects can reappear
- Memory enables regeneration pathways
- But once a population exists, current organization is shaped by:
  - Where defects currently are (position)
  - Current coupling landscape
  - Current resonance state
- Memory is a **historical enabler**, not a current structural controller

## Implications for QMRT

### What This Establishes

1. **Hybrid control structure**: No single DoF dominates the organizational regime
2. **Spatial scaffold carries ~1/3**: Position contributes but doesn't dominate
3. **Internal states matter equally**: Coupling and resonance are as important as geometry
4. **Topology/memory are indirect**: They enable populations but don't shape current structure

### Emerging Picture

> **Proto-spacetime provides a filamentary metric scaffold with hybrid organizational control. The spatial skeleton carries position information, while the coupling landscape and resonance state carry comparable organizational information. Topology and memory serve as enabling variables rather than direct structural controllers.**
